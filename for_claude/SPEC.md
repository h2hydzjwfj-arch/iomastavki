# IOMASTAVKA - ТЗ для улучшения

## Проект
Веб-приложение для логистики Китай → Россия.
HTML/CSS/JS + Node.js (Express). Без фреймворков.

## Что делает
- Калькулятор ставок (маршрут, вес, объём, транспорт, экспедитор)
- ИИ-ассистент с голосом
- База 41 экспедитора (таблица)
- Новости ВЭД (автоперевод на 4 языка)
- Проверка ТН ВЭД
- Генерация статей + аудио-озвучка

## Файлы
- index.html - разметка (одностраничник, слои-окна)
- app.js - вся клиентская логика (~144 KB)
- server.js - Node.js API (~62 KB) - НЕ МЕНЯТЬ логику!
- styles.css - стили (~166 KB)
- package.json - зависимости

## Что улучшить

### 1. Плавность (ПРИОРИТЕТ)
- Анимации переходов между окнами
- Fade-in, slide-up для контента

### 2. Мобильная версия
- Адаптивные отступы

### 3. Типографика

- Line-height 1.6-1.8

### 4. Тёмная тема
- Палитра navy + teal
- Единые тени и границы
- Hover-состояния

### 5. Скорость
- Загрузка главной
- Открытие окон
- Рендер новостей

### 6. Ощущение профи

## НЕ менять

- Структуру HTML (ID и классы)
- Ключи API

## Формат ответа
1. Обновлённый styles.css
2. Патчи к app.js и index.html
3. Резюме изменений
