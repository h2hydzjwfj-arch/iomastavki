# Как загрузить проект в Claude.ai

1. Открой https://claude.ai
2. Войти через Google
3. Создать новый чат
4. Перетащить все файлы из папки for_claude/ (скрепка или drag-and-drop)

## Что написать первым сообщением

Привет! Это мой проект IOMASTAVKA - веб-приложение для логистики Китай-Россия.

Прикрепил файлы: index.html, app.js, server.js, styles.css, package.json, SPEC.md.

Задача: доработать сайт по SPEC.md. Особенно:
1. Плавность анимаций переходов
2. Мобильная адаптация
3. Единая типографика
4. Тёмная тема
5. Скорость загрузки
6. Ощущение профессионального софта

Начни с анализа. Дай план работ. Потом конкретные патчи.

Стиль: минималистичный, как macOS/iOS. Палитра: soft blue + teal.

## Скриншоты

Сделай через Cmd + Shift + 4:
1. Главная (светлая тема)
2. Главная (тёмная тема)
3. Калькулятор ставок
4. ИИ-ассистент с чатом
5. Новости ВЭД
6. Экспедиторы (таблица)
7. Проверка ТН ВЭД
8. Открытая статья

Прикрепи следующим сообщением.

## После ответа Claude

Сохрани обновлённые файлы. Запусти:
./deploy.sh "Дизайн от Claude"
