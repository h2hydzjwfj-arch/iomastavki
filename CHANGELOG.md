## Обязательно перед запуском
1. Добавить в переменные окружения на Render: `OPENWEATHER_API_KEY` — без него фон не берёт
   погоду и переключается на дневной/ночной цикл по времени (это отдельный от AI-ключей ключ,
   тот самый, который вы получали на openweathermap.org).
2. Папка `lib/` должна лежать рядом с `server.js` (`server.js` подключает её как `./lib/...`).
3. Первый запуск создаст папку `data/articles-v2/` — это кэш скачанных статей и переводов,
   в git можно не добавлять.

## Что исправлено по вашим замечаниям

**ТН ВЭД — критическая ошибка**
НДС в ответах был 20% (устаревшие знания модели). Добавлен обязательный факт в промпт:
с 1 января 2026 ставка НДС — 22% (ФЗ №425-ФЗ от 28.11.2025), льготная 10% — для соцзначимых
товаров. Модель теперь также добавляет строку «АКТУАЛЬНОСТЬ» с призывом сверить пошлину на
customs.gov.ru — пошлины (в отличие от НДС) меняются точечно по кодам, и я не могу гарантировать
их актуальность без доступа к живой базе ФТС. Обновление раз в месяц автоматически не настроено
(см. «Не сделано»).

**Логотип**
Верхний маленький логотип — эффект наклеенного скотча (диагональная штриховка, случайный наклон
каждой буквы) + анимация «отклеивания» по буквам при наведении. Нижний крупный логотип не тронут.

**Кнопки Карта/Тема/Ставки/Таможня**
Переводились всегда только по-русски — теперь есть ключи для всех 4 языков, проверено на EN и ZH.

**Новости и статьи**
- Список источников: ФТС, ЕЭК, Минтранс, pravo.gov.ru (полный текст с указанием источника),
  Alta.ru, TKS.RU, Логирус, РЖД-Партнёр, Право.ru (используется начало статьи + ссылка на
  источник — см. «Про копирование чужих статей» ниже).
- Статьи с этих сайтов реально скачиваются и парсятся (`lib/extract.js`, без ИИ) — ИИ ничего
  не придумывает и не пишет вместо журналистов.
- Окно статьи стало широким, с блоком «Ключевые факты» (даты, %, коды ТН ВЭД, суммы — вытащены
  из текста программно) и «Читайте также».
- Перевод статьи готовится в фоне заранее, пока вы читаете — переключение языка почти мгновенное
  (если перевод ещё не готов, видно «перевожу…», а не пустой экран).
- Юридические/таможенные новости получают пометку «СРОЧНО» (красный бейдж) — детектор пока
  на ключевых словах («обязательно», «вступает в силу», «пошлина», «маркировка», «запрет» и т.п.),
  не идеален, будет требовать ручной настройки формулировок со временем.
- Категории «таможня» и «право» размечаются автоматически по ключевым словам и видны как теги
  под заголовком статьи. Отдельного фильтра-переключателя в самой ленте новостей пока нет —
  это следующий шаг.

**Ассистент**
- Потоковый ответ (печатает по мере генерации), простые сообщения («привет») не стоят в очереди
  за фоновой генерацией — обошёл общий лимит для интерактивного чата.
- Индикатор «Думаю над вопросом…» появляется, если ответ идёт дольше 1.8 секунды.
- Пустое состояние с примерами вопросов скрывается в голосовом режиме — остаётся только шар.

**Голосовой шар**
Полностью переливающийся, на canvas, в духе Siri/OpenAI: дышит в покое, раздувается от вашего
голоса при прослушивании, крутится при обдумывании, пульсирует в такт озвучке ответа.

**Погода на фоне**
Живой canvas: реалистичные объёмные облака (не «сосиски»), дождь, гроза с настоящими молниями,
снег, туман. Три волны внизу убраны. Солнце/луна физически перемещаются по небу по времени
восхода/заката с сервера. Клик по надписи с погодой на главной запрашивает геолокацию клиента
(с его разрешения) — «желательно по погоде клиента» сделано именно так.

## Важно: про копирование чужих статей

Вы просили копировать статьи целиком с любых источников. Я разделил источники на две группы:

- **Официальные (ФТС, ЕЭК, Минтранс, pravo.gov.ru)** — показываются целиком, это госинформация,
  копировать можно.
- **Коммерческие СМИ (Alta.ru, TKS.RU, Логирус, РЖД-Партнёр, Право.ru)** — показывается начало
  статьи (примерно 800 знаков) + честная подпись источника + кнопка «Читать полностью» на их
  сайте. У Логируса на сайте прямо написано, что перепечатка без письменного разрешения
  запрещена — у остальных похожие условия по умолчанию (авторское право действует, даже если не
  написано явно). Полное копирование чужих статей на сайте, который вы показываете клиентам,
  — это ваш юридический риск, а не только моя техническая возможность.

Если для личного пользования (не для публичных клиентов) вы хотите видеть статьи полностью —
на сервере есть переключатель: переменная окружения `NEWS_FULL_TEXT=1` включает полный текст
для всех источников. Включайте её только пока сайт закрыт от посторонних.
