# iomastavka — Файл №2

Обновления:
- RU / EN / ZH переводится весь интерфейс без перекрёстной подстановки языков.
- Голос: браузер слушает, превращает речь в текст и после окончания автоматически отправляет запрос локальному ИИ.
- Локальный ИИ работает через WebLLM/WebGPU без OpenAI API-кредитов.
- Расстояние рассчитывается автоматически по выбранным городам.
- Объём и объёмный вес рассчитываются автоматически; фактор зависит от транспорта: авиа 167, авто 400, ЖД 500, море 1000, море+ЖД 1000 кг/м³.
- Новости открываются мгновенно на весь экран; есть изображения, схема маршрута, правовой блок и анимации.
- Ручная тема: ☀ светлая / ☾ тёмная.
- Нажатие на руку Фатимы открывает персональную дневную карту для данных 21.08.2004 16:20, Нижний Новгород.
- Курс внизу увеличен.
