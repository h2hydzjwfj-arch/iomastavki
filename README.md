# iomastavka — Файл №4

Обновление интерфейса и расчёта:
- фиксированные окна; скролл только внутри длинных списков/чата;
- геокодирование городов и полных адресов + подсказки при опечатках;
- расчёт ставки с выводом найденной цены в отдельном окне;
- +5% комиссия для распознанного китайского перевозчика уже включается в финальную цену;
- обязательное предупреждение про терминальные расходы в пункте прибытия;
- формат чисел: целые без `.000`, дробные максимум 3 знака;
- OpenAI API для AI вместо локального WebLLM; web search включён через Responses API;
- «Думаю над вашим ответом…» теперь показывается внутри диалога;
- карта Фатимы собирается/рассыпается частицами, звезда переливается, глаз Хамсы светится;
- статьи поддерживают изображения, галерею и видео из источника.
